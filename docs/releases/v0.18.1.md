# VO PATCH EX v0.18.1 — Playable Bosses

Windows prerelease

Jaguarandi and Z-Gradt join the existing Controller Expansion and Display Expansion features as optional playable Single Player machines. Their original boss abilities, movement, weapons and damage are preserved, including Z-Gradt’s super laser and CANNON charge indicator. Boss portraits, selection animations, cameras, replay and ending behavior follow the upstream implementation.

**Playable Bosses are supported in Single Player only.** Local VS and online multiplayer retain the original eight machines. Experimental Local VS Playable Bosses are not included.

## Unlocking the bosses

Enable **Playable bosses** in the patcher; it is off by default.

| Machine | Unlock requirement |
|---|---|
| Jaguarandi | Defeat Jaguarandi on Very Hard without losing a previous match in that run. |
| Z-Gradt | Complete the game on Very Hard without losing a match. |

Continues count as losses. The optional **Pre-unlock the bosses** option requires Playable bosses and unlocks both immediately. Progress is stored in `bosses.bin` and survives Restore Original and repatching. Z-Gradt’s super laser uses the existing Dash/turbo input.

## Controllers, displays and movies

Existing Custom, Tanita, HORI EX and Raphnet Dreamcast/Saturn profiles, independent player assignment and Custom remapping remain available. Single Display, Dual Display Versus and Dual Display Mirror retain their existing settings, including 4:3, 16:9, 21:9 and 32:9 single-display profiles. Dual Display Versus continues to use the original local multiplayer lineup.

Intro movie playback, natural completion and manual skipping retain upstream ownership. Existing networking, saved configuration and original game settings remain available.

## Install or upgrade

1. Extract the complete Windows ZIP, keeping `_internal` beside `v-on-patcher.exe`.
2. Back up your settings and `bosses.bin`. If the game is already patched, select **Restore Original** before applying this version.
3. Open the patcher, select your original supported disc image/files, choose the patch options and select **Apply**. Keep XInput and F11 Extras enabled for expanded controller and diagnostic controls.
4. Launch the installed `v_on.exe` normally. Use F7 for controllers and F5 for displays; display changes apply on the next launch.

Fresh default installations use 16:9 Single Display. Disabling high resolution starts from original 4:3 unless saved display preferences override it. No administrator privileges, separate game launcher, original executable or game assets are included.

To roll back, use **Restore Original**, then apply the retained v0.18.0 patcher. Keep your saved settings and boss progression backup. Do not patch over a patched installation.

## Compatibility and validation

The integrated display recipes cover English retail and Japanese rerelease executables. Other supported executable variants retain their upstream boss patch tables; full integrated-display and gameplay acceptance is not claimed for those variants.

The single-player boss implementation preserves the accepted Windows-tested baseline. Automated checks cover recipe identity, controller/display regressions, boss options and persistence, Apply/Restore and package integrity. They do not establish gameplay acceptance for every controller, display arrangement or executable revision. The documented hardware inventory is a test record, not an exclusive compatibility list.

Diagnostics default to Off. F11 provides local logging and an explicit export action; nothing is uploaded automatically. Restore Original retains saved display preferences, progression and logs. Modified runtime files are reported rather than silently deleted.
