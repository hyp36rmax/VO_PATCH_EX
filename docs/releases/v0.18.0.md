# VO PATCH EX v0.18.0

Controllers + Display Expansion — prerelease

VO PATCH EX expands Pairomaniac’s V-On Patcher with modern controller and display support while retaining the original installation workflow, gameplay and networking.

- Modern gamepads and dedicated Twin-Stick profiles, including Custom, Tanita, HORI EX and Raphnet Dreamcast/Saturn.
- Independent player controller assignment and configurable Custom mappings.
- Single Display, Dual Display Versus and Dual Display Mirror, with 4:3, 16:9, 21:9 and 32:9 single-display profiles.
- Original movie playback, completion and manual skipping remain under upstream ownership.
- Existing networking functionality and original game settings remain available.

## Install or upgrade

1. Extract the complete Windows ZIP, keeping `_internal` beside `v-on-patcher.exe`.
2. Back up your saved settings. For an already patched installation, use **Restore Original** before applying this version.
3. Open the patcher, select your original supported disc image/files, choose patch options and select **Apply**. Keep XInput and F11 Extras enabled to access expanded controller and diagnostic controls.
4. Launch the installed `v_on.exe` normally. Use F7 for controllers and F5 for displays; display changes apply on the next launch.

Fresh default installations use 16:9 Single Display. Disabling the high-resolution option starts from original 4:3 unless saved display settings override it. No game executable or original game assets are included. No administrator privileges or separate game launcher are required.

The integrated display recipes cover English retail and Japanese rerelease executables. Other executable variants retain the existing upstream patch tables; they are not newly claimed as integrated-display validated.

## Diagnostics and compatibility

Diagnostics default to Off. F11 provides local logging levels and an explicit export action. Nothing is uploaded automatically. Restore Original preserves saved display preferences and logs; modified runtime files are reported rather than silently deleted.

Controller ownership is session-scoped. Reselect disconnected controllers in F7. The documented hardware inventory records tested configurations rather than an exclusive compatibility list. Existing Single and Dual Display acceptance evidence remains applicable to the preserved implementation; this version update does not expand hardware coverage.
